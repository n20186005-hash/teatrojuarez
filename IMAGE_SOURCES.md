# Fuentes de imágenes — Teatro Juárez

Las fotografías usadas por el sitio son imágenes reales del Teatro Juárez alojadas en Wikimedia Commons. Esta entrega mantiene las URLs remotas en el código porque el entorno de construcción no pudo descargar binarios desde Wikimedia. Para una instalación 100 % local, descarga las imágenes y sustituye las constantes de imagen de `src/pages/index.astro` por rutas `/images/...`.
